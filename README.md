# Cory Lutz — Professional Portfolio

A responsive static career website covering technical support, customer success, client operations, leadership and cybersecurity education.

**Live site:** https://cory-b-lutz.github.io/

## Local development

No dependencies or build step are required. From the repository root:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open the local server in your browser. Edit `index.html` for content and `styles.css` for layout and appearance. The site uses system fonts and no JavaScript, external assets or tracking.

## GitHub Pages

The root `index.html` is the entry point. In GitHub Pages settings, serve the repository root from the branch you choose to publish. Review changes before merging or publishing. Local setup does not change Pages settings.
