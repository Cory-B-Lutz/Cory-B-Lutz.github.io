# Macklemore Solutions LLC — Cybersecurity Practicum

**March 3–May 31, 2025** · Part of the Cybersecurity Analyst Diploma at CDI College.

This overview describes coursework, lab and practicum exercises. It does not represent professional production SOC employment. The work developed investigation, documentation, security-awareness and technical reporting skills that also support customer-facing technology work.

## Training areas

The earlier portfolio recorded the following areas of study and practice:

| Area | Topics and tools |
| --- | --- |
| Packet and network analysis | Wireshark, TCP/IP, traffic filtering, firewall-rule validation |
| Vulnerability assessment | OpenVAS, vulnerability prioritization, CVE/CVSS concepts, remediation reporting |
| Security research | OSINT, threat intelligence, MITRE ATT&CK |
| Incident-response exercises | Windows logs, memory-analysis concepts, investigation and reporting |
| Defensive controls | Linux hardening, iptables, layered-defense planning |
| SIEM and malware-analysis exercises | Event correlation, hash verification, investigation concepts |

The original portfolio also described a ZafePass penetration-test simulation using Nmap, Shodan, OWASP ZAP and Nikto, plus a layered-defense scenario for a financial institution. These are training summaries; detailed findings and results cannot be verified from the files currently included here.
